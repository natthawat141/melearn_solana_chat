Melearn Architecture

Local demo · Next.js on port 43123 · SQLite is the live store · Cloudflare is prepared, not running

What the learner hits

  • • Public pages and a lesson preview need no account
  • • Send, hint, example, and practice require a session
  • • Setup is its own page after the first sign-in

What stays on the server

  • • Hints, practice, and grading never go to the model
  • • Quota, ownership, and entitlements are decided here
  • • Wallet signatures are verified locally

Not the running system

  • • Pro pricing is sample copy and does not charge
  • • Accounts and chats live only in SQLite
  • • Workers, D1, R2, and Workers AI are not deployed
