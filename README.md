# Melearn Chat

ครูที่มีคาแรกเตอร์ สำหรับเดโม Solana Colosseum รอบนี้เปิดครูเรย์ (ภาษาอังกฤษ) และครูพาย (คณิตศาสตร์) ให้คุย ขอคำใบ้ ขอตัวอย่าง ทำแบบฝึก แล้วเก็บความคืบหน้า ส่วนโนวา บิต และไทม์โชว์เป็นเร็ว ๆ นี้

บทฟรีทดลองได้โดยไม่สมัครและไม่เชื่อมกระเป๋า บทที่ต้องจ่ายปลดล็อกได้หลังเซิร์ฟเวอร์ตรวจธุรกรรม Solana **devnet** เท่านั้น ข้อความในแชตปลดล็อกบทเรียนไม่ได้

## รันในเครื่อง

ต้องใช้ Node.js 22 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด [http://127.0.0.1:43123](http://127.0.0.1:43123)

```bash
npm test
npm run lint
```

คัดลอก `.env.example` เป็น `.env.local` เมื่อต้องการใส่คีย์โมเดลหรือที่อยู่รับเงินเอง ถ้าไม่ใส่ `AI_API_KEY` ระบบใช้ครูตามบทเรียนบนเซิร์ฟเวอร์อยู่ดี

## เส้นทางเดโม

1. หน้าแรก เลือกครูเรย์หรือครูพาย
2. เปิดบทฟรี คุย แล้วกดขอคำใบ้ ขอตัวอย่าง และลองทำเอง
3. สมัครที่โปรไฟล์ด้วยชื่อกับรหัสผ่าน แล้วรีเฟรช การเรียนของฉันยังอยู่
4. เปิดบทที่ต้องปลดล็อก เชื่อม Phantom หรือ Solflare บน devnet เติม SOL จาก [faucet](https://faucet.solana.com) แล้วอนุมัติ 0.01 SOL
5. เซิร์ฟเวอร์ตรวจผู้จ่าย จำนวนเงิน ที่อยู่รับ บันทึก `melearn:<purchaseId>` และเครือข่าย devnet ก่อนให้สิทธิ์
6. พิมพ์ในแชตว่าจ่ายแล้ว จะไม่ปลดล็อก

ยกเลิกในกระเป๋าแล้วบทยังล็อก ธุรกรรมที่ไม่ตรงรายการจะไม่ให้สิทธิ์ซ้ำ และยืนยันลายเซ็นเดิมซ้ำจะไม่สร้างสิทธิ์ซ้อน

## ข้อมูล

แชต โปรไฟล์ ความคืบหน้า และสิทธิ์อยู่ใน SQLite ที่ `data/melearn.db` บนเชนมีเฉพาะการโอน SOL ทดสอบ ไม่มีชื่อนักเรียนหรือเนื้อแชต

ราคาเดโมคือ 0.01 SOL ต่อบทที่ต้องจ่าย สิทธิ์ในเดโมนี้ไม่มีวันหมดอายุ และยังไม่มีการแบ่งรายได้บนเชน โทเคนนี้เป็น SOL บน devnet ไม่ใช่ USDC จริง

บทฟรีสองบทมาจาก Dev Kit บทสั่งเครื่องดื่มและบทส่วนลดขั้นถัดไปเป็นเนื้อหาเดโมที่เติมเพื่อให้เส้นทางจ่ายเงินทำงานได้

สเปกต้นทางอยู่ใน `docs/specs/` โทเคนสีอยู่ใน `design/tokens.json`
